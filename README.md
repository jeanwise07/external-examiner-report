# External Examiner Report

Copy these prompts into Codex. Install and sign in to Codex first.

## Install

Paste the following into a Codex chat. No GitHub account is needed to download this public skill.

```text
Use $skill-installer to install the external-examiner-report skill from:
https://github.com/jeanwise07/external-examiner-report/tree/main/skills/external-examiner-report
Confirm the installation location and whether the skill can be loaded.
```

Start a new chat after installation. Restart Codex if the skill is not detected.

## Identify courses

Open this year's assessment folder as a local Codex project, then send:

```text
Use $external-examiner-report to review the programme using the materials in this project.
Identify the academic year, institutional report template and available courses.
Show the course codes, official titles, topics, available materials and evidence gaps.
Let me choose the courses for detailed review before drafting the report.
Use the embedded writing style; do not request historical writing samples.
```

## Choose courses

Replace the bracketed text with your selection.

```text
Review [course codes or table row numbers] in detail.
Use programme-level materials and other course designs to assess the programme as a whole.
Explain the review scope and material gaps, then proceed with the review.
```

## Draft

```text
Prepare the institutional form and a detailed English Word appendix using the agreed scope.
Answer every applicable question directly, with a substantial opening curriculum assessment.
Explain the selected courses' main strengths, material concerns and practical improvements.
Provide a separate Chinese explanation with source locations and evidence limitations.
Preserve the originals, leave the signature and signing date blank, and save the outputs in Output.
Check the document layout and report any checks you could not complete.
```

## Revise

```text
Revise [section or passage] to [requested change]. Preserve the rest of the report.
Keep the formal report and supporting evidence explanation consistent.
Save a new version and check the revised layout.
```
