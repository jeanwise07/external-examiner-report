# Annual External Examiner Report

This skill contains the author's writing preferences, question-by-question blueprint, prose examples and base institutional proforma. No past writing sample is required. Use the embedded Writing Style, bundled base form and current assessment materials without requiring an old project directory or chat. New explicit user preferences take precedence.

Evaluate the degree programme as a whole in the examiner's own voice, supported by a detailed review of selected courses. Produce an English formal report and a Chinese explanation of the evidence and limitations unless the user requests otherwise. Converse in the user's language; English skill instructions do not require English conversation. The product is a professional external assessment, not a catalogue of course documents, an item-by-item correction sheet or a journal referee report.

## Base institutional form

The [base proforma 136/924](<references/Proforma for External Examiner's Report (doc.136-924).docx>) is the blank institutional form dated September 2024. Use a working copy as the base Word document, preserving its question wording, fields and institutional layout. If the user supplies a newer form or instructions, use those instead; do not claim that this edition has been confirmed current for a future year. Fill the form and append the detailed responses rather than recreating the institutional form from memory.

Keep the bundled form unchanged. Leave the signature and signing date blank, and confirm any examiner identity details before using them. Instructions within the form are reference content, not authorization to email or submit a report. If the file is unavailable, disclose the gap and use the embedded blueprint for a provisional draft rather than claiming the original form was inspected. No completed historical examiner report is included or needed; the Writing Style section and examples are self-contained.

## Establish the current task and inputs

Distinguish a full annual review, a local revision, and a request for explanation or planning only. If the user says to explain or plan first, do not edit the document yet. Once a revision is authorized, perform it without repeatedly asking for approval.

For a full review, read [Materials and evidence](references/materials-and-evidence.md). Inspect the supplied folder before asking for missing information. Identify:

- The current proforma, examiner guidance, academic year and scope.
- Programme outcomes, regulations, curriculum structure and course descriptions.
- Available course outlines, assessment tasks, marking criteria and marked student work.

Cohort results, assessed capstone work, feedback records and responses to previous recommendations strengthen the assessment. Their absence limits particular conclusions rather than automatically stopping all work.

Use [MFWM annual calibration](references/mfwm-profile.md) to distinguish current findings from any verified follow-up evidence. Reverify academic year, course names, marks, personal details and all current factual conclusions.

## Identify courses and let the user choose the detailed review

Before deeply reviewing student work, inventory the courses and materials. Do not default to MFWM7003/MFWM7017 or first read every submission from every course.

1. Identify course codes, official names and main topics from the folder, programme list, pack contents and outlines. Filenames are discovery clues, not authoritative titles. Verify against current outlines and regulations; flag conflicts rather than guessing. Combine files belonging to the same course, but retain distinctions between academic years or versions. Separate courses merely listed in regulations from courses with supplied review packs; a curriculum menu does not establish actual annual delivery.
2. Check which materials are present: outline, task or examination, rubric, student samples, feedback and known performance bands. This is an initial inventory, not a conclusion about student quality or grading fairness. Mark unexamined coverage as unverified, not complete or absent. Follow the PDF extraction and coverage rules below even at this stage; reading only identification pages must not be described as a full review.
3. Show a concise selection table with one row per course: **number | course code and official title | main topics | materials and visible gaps | possible focus of detailed review**. Derive possible review topics from the actual outline or tasks, such as portfolio analysis, succession cases or individual assessment in group work. These are areas to examine, not presumed deficiencies. Group long lists by subject area without hiding alternatives. Optional recommendations should reflect evidence availability, complementary subject coverage or programme relevance, not the prospect of finding more faults.
4. Ask the user which courses they want discussed in detail. Allow several course codes or row numbers in one reply. A suitable question is: “These are the courses identified in this year's materials. Which would you like me to review in detail? You can select several numbers or course codes; the other courses will support the programme-level assessment.” Use the user's language. Explain any institutionally required number; otherwise do not impose a two-course limit. Do not use a single-choice interface that prevents multiple selections.
5. **Do not determine the focus courses or draft their detailed conclusions before the user chooses.** Meanwhile, read programme outcomes, regulations and the proforma and organize the overall structure. Silence is not acceptance of a recommendation. If the user already selected courses, use that selection without asking again. If the user explicitly delegates selection, choose on evidential and educational grounds, explain the choice, and continue.
6. Record the selected courses, who selected them and material gaps; then apply the detailed reading and sampling plan. Other courses support programme design and documented teaching/assessment judgments. If the user changes the selection, preserve completed reading records and adjust the detailed scope. Do not silently replace a selected course because its evidence is incomplete: explain what can be assessed and let the user decide any substitution.

This is a substantive choice of report focus, not a publication approval. Do not initiate course selection for a local wording change or for editing this skill itself.

## Organize the annual review

Use the embedded Writing Style, blueprint and examples directly. Do not search unrelated folders or require historical writing samples.

Map every current proforma question and subquestion to a judgment, evidence and report location. Related questions may be grouped, but none may disappear. Distinguish programme design from demonstrated student achievement. Read curriculum structure, representative designs from other subject areas and capstone arrangements; detailed review of selected courses is not the sole basis for every answer.

For a full new review, briefly plan scope, sampling, evidence gaps and deliverables. Use review-plan in quick mode when available under the current environment's instructions; if unavailable, make a short inline review without claiming that skill was run. Do not introduce extra approval steps where no unresolved substantive choice exists. Local revisions do not require restarting the full workflow.

## Reading and evidence discipline

- Use pdf-chunker before PDF analysis when available, and inspect its page-coverage report. Use OCR for scanned pages as needed; visually check marks, formulas, tables, charts and handwritten annotations. If a required skill or dependency is unavailable, disclose it and the actual method and coverage; never claim it ran. Where the environment permits a fallback, use page-indexed extraction/OCR with a coverage log and the same visual checks.
- Record extracted, OCR-processed, substantively read and visually verified coverage separately. Extracting an entire file does not mean reviewing every submission in it.
- Read selected course outlines, assessment requirements and marking criteria fully. Review complete submissions under the chosen sampling plan. Verify labels, actual contents, duplicates and missing performance bands first. Expand same-item checks when marking inconsistencies appear.
- Independently verify calculations that materially affect the assessment. Diagnose assessment and learning quality; do not regrade individual students.
- Current conclusions require current evidence. Do not inherit old favorable judgments, course content or claims of implementation.

## Principles for judgments and recommendations

Answer each question directly, then explain the evidence and its educational significance. Where useful, propose improvement. Listing the courses or assessment formats is not an assessment.

Develop the opening curriculum question fully: major domains, their educational value, their connections and engagement with contemporary issues. Do not replace this with general praise and a pointer to a later section.

Explain how teaching supports learning; examine alignment, criteria, individual contribution, consistency and feedback in assessment. Distinguish sample quality, course outcome achievement and graduating-cohort programme outcome achievement.

Concentrate course-specific findings in the appropriate improvement section. Elsewhere evaluate the programme and use examples naturally without repeating the same course names in every answer. Answer in place rather than repeatedly referring readers elsewhere.

Usually prioritize three to five actionable recommendations, but let the evidence determine the number. Each should explain the observation, its consequence for learning and a feasible response. Distinguish local problems from practices worth sharing across the programme. Recognize effective existing arrangements. Do not invent faults to reach a quota or presume the overall assessment must be favorable.

For previous recommendations, distinguish implemented, partly implemented, still needing improvement and not verifiable. Existing arrangements are not automatically evidence of action caused by an earlier review.

## Embedded question-by-question blueprint

This is the HKU MFWM content framework, not a set of annual conclusions. The current proforma takes precedence. If its structure changes, relocate the relevant content by function. Preserve the institution's questions or faithful question prompts, followed immediately by substantive answers.

### 1 Curriculum and programme design and content

**Central concepts, issues and current debates.** This is a substantial opening, often about 300–450 words rather than a short endorsement. Start with the current overall judgment; explain the principal domains and their educational purposes; then discuss their interaction and practical relevance. For MFWM, inspect historical/economic foundations; financial/investment analysis; law, succession and family-office management; psychology, culture, leadership, values and philanthropy. These are review perspectives, not proof that every topic is delivered this year. Adapt to the evidence. Explain connections through concrete decisions involving succession, liquidity or family objectives. Mention contemporary issues only when current materials support them.

**Appropriateness of learning tasks.** Explain what contrasting tasks ask students to do: critical reading, case judgment, interview-based application, investment analysis, research or internship reflection. Explain their disciplinary and master's-level suitability, not just their names.

**International standard of the curriculum.** Assess breadth, analytical depth, independent judgment and professional application. Do not invent comparisons with named overseas institutions or their students.

**Current research informing the curriculum.** Use actual reading lists, tasks and teaching materials. Consider whether students interpret, evaluate and apply research evidence; a bibliography alone does not establish effective research-informed teaching.

**Coherence of the learning experience.** Explain the relationship among core study, electives and capstone work, including progression, overlap, gaps and integration. Adding up credits is not an evaluation of coherence.

The opening question can use a few substantive parallel points. Other curriculum subquestions usually warrant one or two developed paragraphs each. When evidence is limited, narrow the judgment instead of filling space with praise.

### 2 Pedagogy

Address three matters: suitability and effectiveness for learning and outcomes; fit with assigned tasks; and effective or innovative practices. A grouped question prompt is acceptable if separate paragraphs actually address all three.

Assess the combination of conceptual instruction, discussion, cases and practical work, and explain how it supports movement from understanding to application. For substantial projects, examine guidance, mentor contact, interim feedback and communication training. Identify one or two evidenced strengths and opportunities to share them. Without classroom observation, evaluate documented arrangements rather than claiming verified delivery effectiveness. Explain what is distinctive before calling a practice innovative.

### 3 Assessment

Address three matters: suitability, diversity and alignment with outcomes; satisfactory assessment of assigned tasks; and rigor, including descriptors, appropriate and consistent grades, and feedback.

Explain which capabilities each assessment tests and whether the combined evidence covers intended outcomes. Examine individual understanding and contribution within group work. Distinguish rubric design from actual use. Support marking concerns with proportionate evidence and explain whether feedback helps students improve subsequent work. Put detailed course anomalies in the improvement section; here provide a programme-level judgment.

### 4 Performance of students

Distinguish and answer four questions:

- **Quality, strengths and weaknesses:** what the sampled work demonstrates in conceptual understanding, analysis, judgment, evidence and communication. Be specific about strengths and limitations.
- **Course learning outcomes:** which outcomes have demonstrated evidence and where evidence is weaker; do not merely repeat the outcomes.
- **Graduating-cohort programme learning outcomes:** examine evidence for each current official outcome, such as interdisciplinary knowledge, application, ethics/leadership and communication. Opportunities to learn and demonstrated attainment are different judgments.
- **Comparison with reputable international programmes:** distinguish a professional judgment that work meets master's-level expectations from an actual cross-institution comparison, which needs comparable evidence.

State the scope of samples briefly where relevant, without repeating it in every paragraph. Strong design evidence and incomplete cohort evidence can justify different levels of confidence. Do not force identical positive conclusions for rhetorical consistency.

### 5 Areas requiring attention and improvement

This is the main home for specific findings from selected courses. Where supported, begin each course's discussion with one or two sentences recognizing effective design or performance, then develop one or two material concerns. Write natural paragraphs moving from observation to educational consequence and feasible improvement; do not print those three labels repeatedly. Introduce course names naturally at paragraph openings instead of repeating their codes throughout earlier sections.

Combine shared concerns where useful. Do not give every course the same number of faults for symmetry. Include enough diagnosis to justify action, while retaining question numbers, individual marks and calculation details in the supporting evidence record.

### 6 Overall comments and recommendations

Use one or two paragraphs to synthesize the current overall judgment, principal strengths and improvement priorities. Do not summarize every course again. Introduce Recommendations, followed by usually three to five substantive points. Begin each with a short action phrase and continue with a developed paragraph explaining practical implementation and learning value. Let evidence determine the number.

Translate course findings into actions the programme can take without copying Section 5. Use “As recommended last year” only when submission or response records justify that attribution. Otherwise treat the issue as a current observation or an unverified follow-up matter.

### 7 and non-applicable items

For the same MFWM proforma, the user specified N/A for item 7 and no corresponding appendix section. Retain this when the item's meaning and applicability are unchanged and no new requirement applies. If the current template or scope changes materially, evaluate the new requirement rather than applying N/A to a different question.

## Writing Style

**Voice.** Write as an experienced examiner offering accountable professional judgment. Use “I consider”, “In my judgment”, “I would encourage” and “I recommend” naturally; not every paragraph should start with I. Reserve “outstanding”, “excellent”, “clearly demonstrates” and “fully achieved” for proportionate evidence. A positive opening is not compulsory; state serious concerns and their consequences clearly.

**Paragraphs.** Give each paragraph one principal purpose. A useful pattern is one judgment sentence, two or three sentences of explanation/evidence, and a sentence of educational significance or advice; vary this naturally. Use connected prose and concrete examples. A mild tone must not make a specific inconsistency disappear into empty wording such as “further enhancement”. Avoid abstract adjective chains and generic praise.

**Emphasis and lists.** Default to bold italic institutional section headings and Question prompts. Avoid invented mini-headings every few sentences. For independent strengths, improvement points and recommendations, default to a short bold point followed by a developed explanatory paragraph. Keep each bold point with its explanation. Use this treatment selectively, not before every paragraph. Native bullets are appropriate for genuinely parallel lists such as curriculum domains. Avoid nested lists, colored cards and repeated “Key findings / Action points” blocks.

**Word layout.** Outside the current institutional form, default to Times New Roman 12 pt, approximately 1.1 line spacing, 6 pt after paragraphs and justified prose; use about 14 pt for the main title. Keep questions with their opening answer and prevent isolated headings. Preserve the form's paper size, margins, tables and footer; allow natural page flow. Current institutional requirements override these defaults. The Writing Style is self-contained; no historical sample is needed.

**Length.** A complete appendix can start at roughly 2,400–3,000 English words of substantive discussion, adjusted to evidence and requirements. This guards against thin answers, not a mandatory quota. Write enough first, then remove repetition. Do not inflate spacing or repeat summaries to match last year's page count. Item numbers, formulas, sample pages and diagnostic details normally belong in the Chinese evidence explanation, while the English report remains sufficiently concrete to support action.

**Avoid.** Do not write “Specific findings … are brought together in Section 5” or repeated “See Section 5” sentences. “Comprehensive”, “robust” and “holistic” cannot replace explanations. Connect ideas with their substance rather than a sequence of “Furthermore / Moreover / Importantly”. State evidence limitations concisely at the relevant point, generally once; brevity is not permission to overclaim.

## Embedded English examples

These illustrate the voice and reasoning pattern; they are not next year's facts, mandatory recommendations or paragraphs to copy without checking evidence.

**An opening judgment and one domain:**

> My overall assessment of the curriculum is favorable. The programme brings financial analysis into contact with the legal arrangements, relationships and responsibilities through which family wealth is managed. I regard this breadth as a strength because the suitability of an investment or succession decision depends on the family's circumstances as well as its financial consequences.
>
> Financial knowledge and analysis. Asset allocation and investment management provide a basis for examining risk, return and spending needs. Their educational value lies in helping students explain why a proposed portfolio is appropriate for a particular family, including the trade-offs between current commitments and longer-term objectives.
>
> The connections between these subjects deserve equal attention. A succession decision may involve the financing of a family business, the transfer of ownership and different expectations among family members. Bringing these perspectives into a shared case would help students use the breadth of their learning in forming a defensible recommendation.

A complete opening must also discuss the other relevant domains and contemporary issues supported by current evidence. This example is not the entire answer.

**A specific, proportionate assessment observation:**

> The reviewed project work shows that students can organize relevant information and apply the concepts taught. In some reports, however, the proposed recommendation is not fully reconciled with the assumptions used in the analysis. I would ask students to explain whether their results meet the stated objectives and to discuss any remaining trade-offs. This would help them turn separate calculations into a clearer basis for professional advice.

**A natural recommendation paragraph:**

> Strengthen feedback on assessed work. Brief written comments or annotated rubrics would help students understand the main strengths of their work and the improvement most needed. Where substantial projects already include an interim discussion, this provides a useful basis for sharing practice across courses. The purpose should be to make feedback usable before the next assignment, without creating an unnecessarily burdensome process for instructors.

**A concise evidence limitation:**

> The sampled work provides evidence of students' ability to apply the concepts assessed. A judgment about achievement across the graduating cohort would also require aggregate results and assessed work addressing the programme outcomes.

## Deliverables and verification

Default to the completed institutional form plus a detailed English appendix, with a separate Chinese explanation and evidence locations. Do not copy signatures; leave the signing date blank. Exclude student identifiers from the formal English report.

Use available document/PDF tooling to preserve the form and save rerunnable generation or editing scripts, editable prose and recoverable versions. If a required tool is missing, state the concrete limitation rather than pretending to have verified the output. Keep local edits within scope, name substantive versions clearly, and link only the current deliverable.

Before delivery, check every applicable question, treatment of N/A, current year, official names, numerical claims and proportions against source materials. Confirm that English and Chinese conclusions agree, that no unsupported cohort-wide claim appears, and that an existing arrangement has not been described as absent. Render the Word file and visually inspect every page for tables, pagination, headings, question/answer placement, fonts, blank pages and signing area. Report the actual verification method; successful file generation alone is not a layout check.

Explain the outcome, basis and material limits briefly and provide the final files. Deliver locally unless the user explicitly instructs you to send them elsewhere.
