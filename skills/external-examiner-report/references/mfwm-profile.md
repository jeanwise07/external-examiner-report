# MFWM annual calibration

Writing Style, structure and prose examples are embedded in SKILL.md. The [base proforma](<Proforma for External Examiner's Report (doc.136-924).docx>) is bundled in this directory. No completed historical examiner report or previous chat is included or required.

## Current evidence and follow-up

Evaluate the current materials rather than inheriting annual findings. Use verified submission or response records, if supplied, to assess follow-up. Without those records, do not attribute a recommendation to last year's examiner or assert that the institution has or has not implemented it. A generated draft alone does not establish formal submission.

Feedback usability, evidence for programme outcomes, curriculum integration and the adequacy of review materials are possible review areas, not presumed deficiencies or mandatory recommendations. Recognize effective existing arrangements and supported improvement.

## Annual calibration

Let the user select focus courses from the current inventory. Verify official titles against outlines and regulations rather than filenames. Recheck academic year, credits, course counts, outcomes, assessment weights and examiner details.

For the same MFWM proforma and unchanged scope, retain the user's item 7 N/A convention and omit a corresponding appendix section. Reassess if the institution changes the item or scope, as specified in SKILL.md.

Potential concerns about marking, analysis, liquidity, outcome mapping and sample coverage are inspection possibilities, not facts about the programme. Base each material concern on current evidence.
